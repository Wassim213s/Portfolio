# Portfolio de Wassim Siffer

Portfolio de BTS SIO SISR, réparti en plusieurs pages HTML et publié avec GitHub Pages.

## Ouvrir le portfolio

- En local : ouvrir `index.html` dans un navigateur.
- En ligne : https://wassim213s.github.io/Portfolio/

## Organisation des fichiers

- `index.html` : page d’accueil.
- `parcours.html`, `projets.html`, `certifications.html`, `veille.html`, `contact.html` : rubriques du portfolio.
- `styles/` : feuille de style partagée.
- `scripts/` : interactions du site.
- `assets/images/` : photos et logo.
- `documents/` : CV, tableau Excel, aperçu HTML du tableau et compte rendu BioTech.
- `archive/` : document ODS d’origine conservé comme archive.
- `downloads/` : archive ZIP du portfolio à ouvrir dans VS Code.

Le CV et le tableau E5 disposent d’un aperçu intégré sur les pages Parcours et Projets; leurs fichiers restent aussi accessibles au téléchargement.
